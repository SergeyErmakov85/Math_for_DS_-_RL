# Icons

Иконки коллаутов реализованы не файлами, а типографскими знаками в CSS: §, ▣, ▢, ↳, ⊢, ▶, ◈, ※ — см. `Vault/.obsidian/snippets/enf-callouts.css`.

Так сделано намеренно. Знак в псевдоэлементе `::before` наследует цвет темы, масштабируется вместе с текстом, не требует загрузки файлов и переживает экспорт во все пять форматов сборки. Растровая или SVG-иконка не даёт ни одного из этих свойств.

Каталог существует для случая, когда понадобится иконка, которую знаком не выразить. В версии 1.0.0 такой нужды нет.
