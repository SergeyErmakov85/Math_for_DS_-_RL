# Хранилище ENF

Готовое хранилище Obsidian с настроенными темами, шаблонами и запросами. Скопируйте эту папку в удобное место либо откройте её как есть.

## Первый запуск

1. Obsidian → **Open folder as vault** → выбрать эту папку.
2. Открыть [`_meta/mathjax-preamble.md`](_meta/mathjax-preamble.md) — без этого не работают макросы раскраски формул. Заметку стоит закрепить, чтобы она открывалась вместе с хранилищем.
3. Проверить, что в **Settings → Appearance → CSS snippets** включены `enf-tokens`, `enf-math`, `enf-callouts`. Они включены в поставке; список хранится в `.obsidian/appearance.json`.
4. При желании установить плагины Templater, Dataview и Tasks — все три из официального каталога сообщества.

Хранилище работает и **без плагинов**: структура, темы, оформление формул и коллаутов — на штатных возможностях Obsidian. Без плагинов недоступны автозаполнение шаблонов и динамические списки материалов; содержимое при этом не ломается.

## Структура

| Папка | Что хранит |
|-------|------------|
| `00 Inbox` | Черновики и необработанные заметки. Сюда попадают новые файлы. |
| `10 Лекции` | Материалы занятий, Learning Mode |
| `20 Книги` | Главы книг и методичек, Publication Mode |
| `30 Статьи` | Научные работы и конспекты чужих статей |
| `40 Задачники` | Листки задач с решениями |
| `50 Доказательства` | Отдельные доказательства, на которые ссылаются другие материалы |
| `90 Ресурсы` | Вложения: изображения, PDF, данные |
| `_meta` | Служебное: преамбула MathJax, справка по палитре |
| `_templates` | Templater-шаблоны |
| `_canvas` | Canvas-схемы: карты дисциплин и структура курсов |

Числовые префиксы задают порядок в боковой панели и не дают папкам перемешаться при сортировке по алфавиту.

## Соглашения

- Имя файла совпадает с полем `title` фронтматтера.
- Внутри хранилища допустимы wiki-ссылки; в материалах, идущих в сборку Pandoc, — только относительные пути (`ENF-TYPO-051`).
- Вложения кладутся в `90 Ресурсы` — это задано в `.obsidian/app.json`, отдельных действий не требуется.
- Заметка без фронтматтера считается черновиком и не попадает в списки Dataview.
