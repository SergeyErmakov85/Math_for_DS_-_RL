# Templates

Файлы этого раздела физически лежат внутри хранилища — в `Vault/_templates/`.

Причина в устройстве Obsidian: он видит только содержимое своей папки. Хранить рабочую копию здесь и вторую внутри хранилища означало бы два источника истины и неизбежное расхождение между ними.

Что там находится: Templater-версии шаблонов: `Lecture.md`, `Proof.md`.

Открыть: [`../Vault/`](../Vault/) как хранилище Obsidian. Инструкция — [`../Vault/README.md`](../Vault/README.md).
