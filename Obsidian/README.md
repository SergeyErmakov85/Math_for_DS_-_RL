# Хранилище ENF

Хранилищем Obsidian служит весь репозиторий `Math_for_DS_&_RL`: откройте его корень через **Open folder as vault**. В этой папке — только служебные заметки хранилища. Полная инструкция по установке и настройкам — [`docs/04_Obsidian_Guide.md`](../docs/04_Obsidian_Guide.md).

## Первый запуск

1. Obsidian → **Open folder as vault** → выбрать корень репозитория.
2. Разрешить плагины сообщества: **Turn on community plugins** и, если Obsidian спросит, **Trust author**. В поставке один плагин — Extended MathJax; он читает `preamble.sty` из корня хранилища при старте, и макросы раскраски формул доступны сразу.
3. Проверить, что в **Settings → Appearance → CSS snippets** включены `enf-tokens`, `enf-math`, `enf-callouts`, `enf-code`. Они включены в поставке; список хранится в `.obsidian/appearance.json`.
4. При желании установить плагины Templater, Dataview и Tasks из официального каталога сообщества.

**Если плагины оставлены выключенными**, откройте [Преамбулу MathJax](mathjax-preamble.md) один раз за сессию Obsidian — макросы объявятся до конца сессии.

## Структура хранилища

| Папка | Что хранит |
|-------|------------|
| `math-textbook/` | Учебник «Математика для ML и RL»: 7 частей, 51 раздел |
| `materials/` | Отдельные лекции по дисциплинам (`Calculus/`, `Linear_Algebra/`, `Optimization/`, `Probability/`, `RL/`, `Logic/`). Новые заметки Obsidian создаёт здесь |
| `examples/` | Эталонные документы в двух режимах раскраски |
| `templates/` | Шаблоны документов; `templates/templater/` — версии для Templater |
| `Figures/` | Вложения: изображения, вставленные в заметки |
| `svg/`, `mermaid/` | Библиотеки иллюстраций и диаграмм |
| `docs/`, `agents/` | Правила оформления и инструкции для ИИ-агентов |
| `Obsidian/` | Служебные заметки хранилища — эта папка |

## Соглашения

- Имя файла латиницей, совпадает по смыслу с полем `title` фронтматтера; режим раскраски — в суффиксе: `Topic.learning.md`, `Topic.publication.md`.
- Ссылки — относительными путями в Markdown-формате; Obsidian вставляет их так сам (`.obsidian/app.json`). Wiki-ссылки допустимы только в служебных заметках этой папки (`ENF-TYPO-051`).
- Заметка без фронтматтера считается черновиком и не попадает в списки Dataview.
