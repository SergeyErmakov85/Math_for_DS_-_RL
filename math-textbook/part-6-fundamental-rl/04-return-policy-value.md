# Глава 4. Возврат, политики и функции ценности

## Зачем это нужно

[Глава 3](03-mdp.md) описала среду, но не сказала, чего агент добивается. Наивный ответ «получать награду» недостаточен: награда приходит на каждом шаге, и максимизировать её поодиночке значит быть близоруким — агент схватит мелкое немедленное вознаграждение и упустит большое отложенное.

Глава вводит три понятия, превращающие расплывчатую цель в математическую задачу. Возврат говорит, что именно максимизируется. Политика говорит, что мы ищем. Функция ценности связывает первое со вторым и делает поиск возможным.

## Обозначения

| Символ | Значение | Роль |
|--------|----------|------|
| $\enfVar{s}, \enfVar{s}' \in \mathcal{S}$ | состояния | `variable` |
| $a \in \mathcal{A}$ | действие | — |
| $\pi(a\mid \enfVar{s})$ | политика | — |
| $\enfTgt{r}_t$ | награда на шаге $t$ | `target` |
| $\enfPar{\gamma}$ | коэффициент дисконтирования | `parameter` |
| $\enfOp{G}_t$ | возврат с шага $t$ | `operator` |
| $\enfOp{V}^{\pi}, \enfOp{Q}^{\pi}$ | функции ценности | `operator` |
| $\enfOp{A}^{\pi}$ | функция преимущества | `operator` |

## Возврат

> [!definition] Определение 1. Возврат
> **Возвратом** (return) с момента $t$ называется дисконтированная сумма будущих наград:
> $$\enfOp{G}_t = \enfTgt{r}_{t+1} + \enfPar{\gamma}\,\enfTgt{r}_{t+2} + \enfPar{\gamma}^{2}\,\enfTgt{r}_{t+3} + \dots = \sum_{k=0}^{\infty}\enfPar{\gamma}^{k}\,\enfTgt{r}_{t+k+1}.$$

Три обстоятельства стоит проговорить.

**Возврат смотрит только вперёд.** Награды, полученные до момента $t$, в него не входят. Прошлое не подлежит оптимизации, а значит и учёту в цели.

**Ряд сходится при $\enfPar{\gamma} < 1$ и ограниченных наградах**, причём $|\enfOp{G}_t| \le \enfTgt{r}_{\max}/(1-\enfPar{\gamma})$ — доказательство в [Части I](../part-1-limits-series/02-infinite-series.md). Это единственное, что делает определение осмысленным в бесконечном эпизоде.

**Возврат самоподобен:**

$$
\enfOp{G}_t = \enfTgt{r}_{t+1} + \enfPar{\gamma}\,\enfOp{G}_{t+1}.
$$

Это равенство — источник всех рекурсивных уравнений RL; вывод занимает три строки и приведён в [Части I](../part-1-limits-series/03-limits-in-rl.md).

**Пример 1.** Награды $2, 0, 0, 5$, эпизод завершён, $\enfPar{\gamma} = 0{,}9$. Тогда

$$
\enfOp{G}_0 = 2 + 0{,}9\cdot 0 + 0{,}81\cdot 0 + 0{,}729\cdot 5 = 2 + 3{,}645 = 5{,}645.
$$

Проверим самоподобие: $\enfOp{G}_3 = 5$, $\enfOp{G}_2 = 0 + 0{,}9\cdot 5 = 4{,}5$, $\enfOp{G}_1 = 0 + 0{,}9\cdot 4{,}5 = 4{,}05$, $\enfOp{G}_0 = 2 + 0{,}9\cdot 4{,}05 = 5{,}645$ ✓. $\blacksquare$

## Политика

> [!definition] Определение 2. Политика
> **Политикой** (policy) называется распределение над действиями при каждом состоянии: $\pi(a \mid \enfVar{s}) = \mathbb{P}(A_t = a \mid S_t = \enfVar{s})$. Детерминированную политику записывают как функцию $\pi(\enfVar{s}) = a$.

Политика — это и есть то, что ищется: описание поведения агента. Задача RL формулируется как поиск политики, максимизирующей ожидаемый возврат.

*Таблица 1. Виды политик.*

| Вид | Запись | Где применяется |
|---|---|---|
| Детерминированная | $\pi(\enfVar{s}) = a$ | результат жадного выбора по $Q$ |
| Стохастическая дискретная | softmax над оценками | дискретные действия, методы градиента политики |
| Стохастическая непрерывная | нормальное распределение | непрерывное управление, RollerAgent |
| $\varepsilon$-жадная | смесь жадной и равномерной | обучение табличных методов и DQN |

Важно, что политика зависит только от состояния, а не от времени: в бесконечном MDP оптимальная политика стационарна, и это не упрощение, а теорема теории MDP.

## Функции ценности

> [!definition] Определение 3. Функции ценности
> $$\enfOp{V}^{\pi}(\enfVar{s}) = \mathbb{E}_{\pi}\!\left[\enfOp{G}_t \mid S_t = \enfVar{s}\right], \qquad
> \enfOp{Q}^{\pi}(\enfVar{s}, a) = \mathbb{E}_{\pi}\!\left[\enfOp{G}_t \mid S_t = \enfVar{s},\ A_t = a\right].$$

> [!intuition] Зачем нужны обе
> Функция $\enfOp{V}$ отвечает «насколько хорошо здесь быть»; функция $\enfOp{Q}$ — «насколько хорошо здесь сделать вот это». Вторая содержательнее ровно на один вопрос — тот самый, который нужен для улучшения политики. Зная лишь $\enfOp{V}$, чтобы сравнить действия, надо знать, куда они ведут, то есть иметь модель среды. Зная $\enfOp{Q}$, сравнение делается напрямую.
>
> Отсюда практическое правило: безмодельные алгоритмы учат $\enfOp{Q}$, методы с моделью или с отдельным актором могут обойтись $\enfOp{V}$.

Связь между функциями:

$$
\enfOp{V}^{\pi}(\enfVar{s}) = \sum_{a}\pi(a\mid \enfVar{s})\,\enfOp{Q}^{\pi}(\enfVar{s},a).
$$

Ценность состояния есть среднее ценностей действий, взвешенное вероятностями политики. Для детерминированной политики сумма вырождается в одно слагаемое.

## Преимущество

> [!definition] Определение 4. Преимущество
> $$\enfOp{A}^{\pi}(\enfVar{s},a) = \enfOp{Q}^{\pi}(\enfVar{s},a) - \enfOp{V}^{\pi}(\enfVar{s}).$$

Преимущество отвечает: «насколько это действие лучше того, что политика обычно делает здесь». Его среднее по политике равно нулю:

$$
\sum_{a}\pi(a\mid \enfVar{s})\,\enfOp{A}^{\pi}(\enfVar{s},a) = \enfOp{V}^{\pi}(\enfVar{s}) - \enfOp{V}^{\pi}(\enfVar{s}) = 0,
$$

где первое равенство — подстановка связи между $\enfOp{V}$ и $\enfOp{Q}$. $\blacksquare$

Нулевое среднее — не любопытный факт, а причина, по которой преимущество снижает дисперсию оценки градиента политики ([Часть V](../part-5-policy-optimization/02-policy-gradient-derivation.md)): множитель центрирован, и его масштаб на порядки меньше масштаба возврата.

**Пример 2.** В состоянии три действия с ценностями $\enfOp{Q} = (12;\ 10;\ 8)$, политика равновероятная. Тогда $\enfOp{V} = 10$, а преимущества равны $(+2;\ 0;\ -2)$. Возвраты различались на 20 % от своей величины, преимущества — знаком. Для обучения существенна вторая картина. $\blacksquare$

## Оптимальность

> [!definition] Определение 5. Оптимальные функции ценности
> $$\enfOp{V}^{*}(\enfVar{s}) = \max_{\pi}\enfOp{V}^{\pi}(\enfVar{s}), \qquad \enfOp{Q}^{*}(\enfVar{s},a) = \max_{\pi}\enfOp{Q}^{\pi}(\enfVar{s},a).$$

Существенный и не самоочевидный факт теории MDP: для конечного MDP существует **одна** политика, оптимальная одновременно во всех состояниях, и её можно выбрать детерминированной. Не приходится выбирать, какое состояние оптимизировать, — компромисса между состояниями не возникает.

Оптимальная политика извлекается из $\enfOp{Q}^{*}$ без модели среды:

$$
\pi^{*}(\enfVar{s}) = \arg\max_{a}\enfOp{Q}^{*}(\enfVar{s},a).
$$

Отсюда план всех методов, основанных на ценности: найти $\enfOp{Q}^{*}$, а политику получить даром. Как её найти — содержание [главы 5](05-bellman-equations.md) и [главы 6](06-model-free-rl.md).

## Что стоит запомнить

1. Максимизируется возврат — дисконтированная сумма будущих наград, а не награда текущего шага; прошлые награды в цель не входят.
2. Самоподобие возврата $G_t = r_{t+1} + \gamma G_{t+1}$ — источник всех рекурсивных уравнений RL.
3. Функция $Q$ содержательнее $V$ ровно на возможность сравнить действия без модели среды; отсюда деление алгоритмов.
4. Преимущество имеет нулевое среднее по политике, и потому его использование снижает дисперсию, не внося смещения.
5. Для конечного MDP существует единая детерминированная политика, оптимальная во всех состояниях сразу.

## Проверка себя

1. Награды $1, 1, 1, 10$, $\gamma = 0{,}8$. Найдите $G_0$ двумя способами: напрямую и через рекурсию.
2. Политика равновероятна над двумя действиями с $Q = (6, 2)$. Найдите $V$ и преимущества обоих действий.
3. Почему из знания только $V^{\pi}$ нельзя улучшить политику без модели среды?
4. Докажите, что среднее преимущество по политике равно нулю.
5. Почему существование единой оптимальной политики для всех состояний — нетривиальное утверждение? Что было бы, если бы его не было?
