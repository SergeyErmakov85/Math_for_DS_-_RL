# Мини-глоссарий

Термины Части VI со ссылкой на главу, где понятие вводится. Математические термины анализа и рядов — в [глоссарии Части I](../part-1-limits-series/11-glossary.md).

## Среда и задача

**Агент** (agent) — субъект, выбирающий действия и получающий награды. → [глава 3](03-mdp.md)

**Среда** (environment) — всё, что не является агентом; отвечает на действия сменой состояния и наградой. → [глава 3](03-mdp.md)

**MDP** (Markov Decision Process) — пятёрка $\langle \mathcal{S}, \mathcal{A}, P, R, \gamma\rangle$, формальная модель задачи с последствиями. → [глава 3](03-mdp.md)

**Марковское свойство** (Markov property) — условная независимость будущего от прошлого при известном настоящем. Характеристика выбранного описания состояния, а не мира. → [глава 3](03-mdp.md)

**POMDP** — частично наблюдаемый MDP: агент видит функцию состояния, а не само состояние. → [глава 3](03-mdp.md)

**Эпизод** (episode) — отрезок взаимодействия от начального состояния до терминального. → [глава 4](04-return-policy-value.md)

**Терминальное состояние** — состояние, после которого взаимодействие прекращается. Не то же самое, что обрыв по лимиту шагов. → [глава 3](03-mdp.md)

## Цель и оценки

**Награда** (reward), $r$ — скалярный сигнал за шаг. → [глава 4](04-return-policy-value.md)

**Возврат** (return), $G_t$ — дисконтированная сумма будущих наград. → [глава 4](04-return-policy-value.md)

**Коэффициент дисконтирования** (discount factor), $\gamma$ — вес будущих наград; определяет горизонт планирования и скорость сходимости. → [глава 4](04-return-policy-value.md)

**Политика** (policy), $\pi(a \mid s)$ — распределение над действиями при каждом состоянии; то, что ищется. → [глава 4](04-return-policy-value.md)

**Функция ценности состояния** (state-value function), $V^{\pi}(s)$ — ожидаемый возврат из состояния. → [глава 4](04-return-policy-value.md)

**Функция ценности действия** (action-value function), $Q^{\pi}(s,a)$ — ожидаемый возврат при заданном первом действии. → [глава 4](04-return-policy-value.md)

**Преимущество** (advantage), $A^{\pi}(s,a) = Q^{\pi} - V^{\pi}$ — насколько действие лучше среднего; имеет нулевое среднее по политике. → [глава 4](04-return-policy-value.md)

## Уравнения и операторы

**Уравнение ожиданий Беллмана** — рекурсивное соотношение для фиксированной политики; линейно. → [глава 5](05-bellman-equations.md)

**Уравнение оптимальности Беллмана** — вариант с максимумом по действиям; нелинейно. → [глава 5](05-bellman-equations.md)

**Оператор Беллмана**, $T$ — преобразование функций ценности; сжимает с коэффициентом $\gamma$. → [глава 5](05-bellman-equations.md)

**Итерация ценности** (value iteration) — многократное применение оператора Беллмана. → [глава 5](05-bellman-equations.md)

**Итерация по политикам** (policy iteration) — чередование точной оценки политики и жадного улучшения. → [глава 5](05-bellman-equations.md)

## Обучение без модели

**Бутстрэппинг** (bootstrapping) — использование собственной оценки в составе цели обучения. → [глава 6](06-model-free-rl.md)

**TD-ошибка** (temporal difference error), $\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$ — невязка уравнения Беллмана на одном переходе. → [глава 6](06-model-free-rl.md)

**Метод Монте-Карло** — обучение на фактическом возврате; несмещён, дисперсия высока. → [глава 6](06-model-free-rl.md)

**TD-обучение** — обучение на цели с бутстрэппингом; смещено, дисперсия низка. → [глава 6](06-model-free-rl.md)

**SARSA** — управление на политике: цель строится по действию, которое агент выбрал. → [глава 6](06-model-free-rl.md)

**Q-обучение** (Q-learning) — управление вне политики: цель строится по максимуму. → [глава 6](06-model-free-rl.md)

**На политике / вне политики** (on-policy / off-policy) — совпадает ли оцениваемая политика с той, по которой агент действует. → [глава 6](06-model-free-rl.md)

**Условия Роббинса — Монро** — требования $\sum\alpha_n = \infty$, $\sum\alpha_n^{2} < \infty$ к скоростям обучения. → [глава 6](06-model-free-rl.md)

## Следы и многошаговые методы

**$n$-шаговый возврат** — цель с $n$ настоящими наградами и последующей оценкой. → [глава 7](07-eligibility-traces.md)

**$\lambda$-возврат** — среднее $n$-шаговых возвратов с геометрическими весами. → [глава 7](07-eligibility-traces.md)

**След пригодности** (eligibility trace), $e_t(s)$ — мера недавности и частоты посещения состояния. → [глава 7](07-eligibility-traces.md)

**Прямой и обратный взгляд** (forward / backward view) — две эквивалентные формулировки TD($\lambda$); вторая вычислима онлайн. → [глава 7](07-eligibility-traces.md)

**GAE** (Generalized Advantage Estimation) — тот же $\lambda$-механизм, применённый к преимуществу; параметр `lambd` в конфигурации. → [глава 7](07-eligibility-traces.md)

## Аппроксимация и глубокое RL

**Аппроксимация функции** (function approximation) — замена таблицы параметрической функцией; даёт обобщение, отнимает гарантии. → [глава 8](08-function-approximation.md)

**Полуградиент** (semi-gradient) — правило обновления, в котором производная цели отброшена; градиентом никакой функции не является. → [глава 8](08-function-approximation.md)

**Смертельная триада** (deadly triad) — сочетание аппроксимации, обучения вне политики и бутстрэппинга; допускает расходимость. → [глава 8](08-function-approximation.md)

**Буфер воспроизведения** (replay buffer) — хранилище переходов для обучения на случайных выборках. → [глава 8](08-function-approximation.md)

**Целевая сеть** (target network) — замороженная копия параметров для вычисления цели. → [глава 8](08-function-approximation.md)

**DQN** (Deep Q-Network) — Q-обучение с нейросетью, буфером воспроизведения и целевой сетью. → [глава 8](08-function-approximation.md)

**Double DQN** — вариант, устраняющий систематическое завышение за счёт разделения выбора и оценки действия. → [глава 8](08-function-approximation.md)

## Методы градиента политики

**Логарифмический трюк** (log-derivative trick) — тождество $\nabla p = p\,\nabla\ln p$; переводит градиент вероятности в математическое ожидание. → [глава 9](09-policy-gradients.md)

**Теорема о градиенте политики** — выражение градиента целевой функции без производной модели среды. → [глава 9](09-policy-gradients.md)

**REINFORCE** — простейший алгоритм градиента политики с весом-возвратом; несмещён, дисперсия очень высока. → [глава 9](09-policy-gradients.md)

**Базис** (baseline) — вычитаемая функция состояния; не вносит смещения, снижает дисперсию. → [глава 9](09-policy-gradients.md)

**Актор-критик** (actor-critic) — политика и функция ценности, обучаемые совместно; TD-ошибка служит оценкой преимущества. → [глава 9](09-policy-gradients.md)

**PPO** (Proximal Policy Optimization) — актор-критик с клиповым ограничением, позволяющим переиспользовать данные. → [Часть V](../part-5-policy-optimization/04-ppo.md)

## Исследование

**Дилемма исследования и использования** (exploration–exploitation) — конфликт между получением награды и получением знания. → [глава 2](02-multi-armed-bandits.md)

**Многорукий бандит** (multi-armed bandit) — задача RL без состояний. → [глава 2](02-multi-armed-bandits.md)

**$\varepsilon$-жадная стратегия** — жадный выбор с вероятностью $1-\varepsilon$, случайный с вероятностью $\varepsilon$. → [глава 2](02-multi-armed-bandits.md)

**UCB** (Upper Confidence Bound) — выбор по верхней границе доверительного интервала оценки. → [глава 2](02-multi-armed-bandits.md)

**Сожаление** (regret) — накопленная разность между наградой всезнающего агента и фактической. → [глава 2](02-multi-armed-bandits.md)

**Энтропийный член** — слагаемое целевой функции, поощряющее разброс политики; параметр `beta`. → [Часть V](../part-5-policy-optimization/04-ppo.md)
