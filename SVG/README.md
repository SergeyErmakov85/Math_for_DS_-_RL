# SVG — библиотека векторных иллюстраций

Единая редактируемая библиотека вместо разрозненных рисунков. Каждый файл — обычный SVG, который открывается в текстовом редакторе, правится вручную и наследует цвета палитры через CSS-переменные.

| Подкаталог | Содержимое |
|------------|------------|
| [`axes/`](axes/) | Координатные оси, сетки, разметка |
| [`functions/`](functions/) | Графики функций, касательные, площади под кривой |
| [`probability/`](probability/) | Вероятностные деревья, распределения, диаграммы Венна |
| [`rl/`](rl/) | Цепи Маркова, диаграмма уравнения Беллмана, цикл «агент — среда» |
| [`nn/`](nn/) | Нейронные сети, схема обратного распространения |
| [`algorithms/`](algorithms/) | Блок-схемы алгоритмов |

Полный список с превью — в [`CATALOG.md`](CATALOG.md).

## Единые требования

- Холст `800 × 500` для широких схем, `500 × 500` для квадратных, `800 × 300` для полос. Сетка — шаг 20.
- Цвета берутся **только** из палитры: `var(--enf-color-variable, #RRGGBB)` — переменная с запасным значением, чтобы файл был корректен и вне Obsidian.
- Каждый файл содержит `<title>` и `<desc>` — они становятся alt-текстом при вставке.
- Подписи — текстом, а не кривыми: текст должен оставаться редактируемым и доступным для поиска.

Правила подробно описаны в [`../docs/StyleGuide/Diagrams.md`](../docs/StyleGuide/Diagrams.md).
