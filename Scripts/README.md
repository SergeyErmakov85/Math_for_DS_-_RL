# Scripts — сборка, проверки, генераторы

Скрипты написаны на **Node.js** (логика проверок) и **PowerShell 7** (оркестрация). Python не используется намеренно — обоснование в журнале решений [`../docs/reference/PROGRESS.md`](../docs/reference/PROGRESS.md).

## Проверки качества, уровень 1

| Скрипт | Что ловит |
|--------|-----------|
| [`check.ps1`](check.ps1) | Запускает все проверки ниже и печатает сводку |
| [`check-frontmatter.mjs`](check-frontmatter.mjs) | Отсутствие фронтматтера, незаполненные обязательные поля, недопустимые значения `enf_mode` и `discipline` |
| [`check-links.mjs`](check-links.mjs) | Битые внутренние ссылки, несуществующие якоря, wiki-ссылки вне хранилища, неинформативный текст ссылки |
| [`check-colors.mjs`](check-colors.mjs) | HEX вне единого источника, прямые команды цвета, превышение лимита тонов, запрещённые тона в Publication Mode, именованные цвета в SVG |
| [`check-alt.mjs`](check-alt.mjs) | Изображения без alt-текста, alt-текст из одних общих слов, SVG без `<title>` и `<desc>` |
| [`check-structure.mjs`](check-structure.mjs) | Число и вложенность заголовков, формулы в заголовках, блоки кода без языка, запрещённые окружения LaTeX и типы Mermaid, доказательства без символа окончания, забытые служебные комментарии |
| [`check-contrast.mjs`](check-contrast.mjs) | Контраст палитры по WCAG и различимость тонов при дейтеранопии и протанопии |

## Генераторы

Порождают файлы из единого источника цветов `css/enf-tokens.css`. Результаты помечены как порождённые; правки в них теряются при следующем запуске.

| Скрипт | Что создаёт |
|--------|-------------|
| [`gen-latex-colors.mjs`](gen-latex-colors.mjs) | `Build/templates/enf-colors.tex` — `\definecolor` и макросы ролей для XeLaTeX |
| [`gen-mermaid-init.mjs`](gen-mermaid-init.mjs) | `mermaid/init-config.md` и init-директивы во всех шаблонах Mermaid |
| [`gen-obsidian-css.mjs`](gen-obsidian-css.mjs) | `Obsidian/Vault/.obsidian/snippets/enf-tokens.css` — Obsidian не читает CSS извне хранилища |

## Сборка

| Скрипт | Назначение |
|--------|------------|
| [`build.ps1`](build.ps1) | Собирает документ в PDF, EPUB, HTML, DOCX и Reveal.js; перед сборкой прогоняет проверки и пересоздаёт порождаемые файлы |
| [`convert-svg.ps1`](convert-svg.ps1) | Создаёт PDF-копии иллюстраций библиотеки для вставки в PDF; требует `rsvg-convert` или Inkscape |

## Общее

| Файл | Содержимое |
|------|------------|
| [`enf-lib.mjs`](enf-lib.mjs) | Чтение с нормализацией переводов строк, обход файлов, разбор фронтматтера, разбор блоков кода, формат отчёта |

Все проверки читают файлы через `readText()` из этой библиотеки. Это не стилистическое требование: в рабочем каталоге на Windows переводы строк смешанные, а точка в регулярных выражениях JavaScript не совпадает с `\r`. Прямое чтение приводит к тому, что поле фронтматтера или ограждение блока кода перестают распознаваться, а ошибка выглядит как отсутствующее поле.

## Запуск

```powershell
# все проверки по репозиторию
pwsh Scripts/check.ps1 .

# по одному каталогу, без проверки палитры
pwsh Scripts/check.ps1 examples/ -SkipPalette

# отдельная проверка
node Scripts/check-colors.mjs examples/

# пересоздать все порождаемые файлы
npm run gen

# окружение сборки: что установлено, что чего не хватает
pwsh Scripts/build.ps1 -CheckEnv

# сборка во все пять форматов
pwsh Scripts/build.ps1 -Source examples/Bellman_Equation.learning.md -All
```

## Коды возврата

| Код | Значение |
|-----|----------|
| `0` | Нарушений нет |
| `1` | Найдены нарушения уровня «Обязательно» либо часть форматов не собралась |
| `2` | Ошибка запуска: нет входного пути, недоступна обязательная зависимость |

Ненулевой код останавливает сборку. Предупреждения уровня «Рекомендуется» печатаются, но код возврата не меняют.
