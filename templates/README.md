# Templates — универсальные шаблоны документов

Шесть Markdown-шаблонов, покрывающих все типы материалов фреймворка. Шаблоны обычные — без плагинов и подстановок; Templater-версии для Obsidian лежат в [`../Obsidian/Templates/`](../Obsidian/Templates/).

| Шаблон | Тип материала | Режим по умолчанию |
|--------|---------------|--------------------|
| [`Lecture.md`](Lecture.md) | Лекция, занятие, семинар | `learning` |
| [`BookChapter.md`](BookChapter.md) | Глава книги или методички | `publication` |
| [`ResearchPaper.md`](ResearchPaper.md) | Научная статья, препринт | `publication` |
| [`ExerciseSheet.md`](ExerciseSheet.md) | Задачник, листок с задачами | `learning` |
| [`Proof.md`](Proof.md) | Отдельное доказательство или вывод | `learning` |
| [`Presentation.md`](Presentation.md) | Слайды (Reveal.js) | `publication` |

## Как пользоваться

```powershell
Copy-Item templates/Lecture.md "Лекция 01 — Предел функции.md"
```

Затем заполните фронтматтер и удалите служебные комментарии `<!-- ENF: ... -->`, которые объясняют структуру. Проверка `Scripts/check.ps1` предупредит, если такие комментарии остались в готовом документе.

## Что общего у всех шаблонов

- Фронтматтер с обязательными полями (`title`, `enf_mode`, `discipline`, `tags`) — состав задан правилами `ENF-PUB-001`–`ENF-PUB-004`.
- Раздел «Обозначения» перед первым содержательным разделом: все символы определяются до первого использования.
- Единая иерархия заголовков: `#` — только заголовок документа, содержательные разделы начинаются с `##`.
- Блок «Проверка себя» или «Итоги» в конце — состав зависит от типа материала.
