# AGENTS.md — указатель

Ermakov Notes Framework — фреймворк для научных и образовательных материалов по математике, Data Science и Reinforcement Learning. Содержание материалов на русском; имена файлов, код и команды — на английском.

Правила живут не здесь. Этот файл существует только потому, что агент, открывший репозиторий, читает корень первым.

| Что нужно | Читать |
|-----------|--------|
| Короткая точка входа: пять правил, роли цвета, лимиты раскраски | [`agents/AGENTS.md`](agents/AGENTS.md) |
| Полная конституция: правила генерации и проверки, структура вывода, запреты | [`agents/CODEX.md`](agents/CODEX.md) |
| Написание и правка материалов | [`agents/CLAUDE.md`](agents/CLAUDE.md) |
| Перенос PDF, сканов и конспектов в Markdown | [`agents/DOCUMENT_CONVERSION.md`](agents/DOCUMENT_CONVERSION.md) |
| Нормы с номерами `ENF-*` | [`docs/`](docs/) — начните с [`docs/README.md`](docs/README.md) |

Перед словами «готово» прогоните проверки: `pwsh Scripts/check.ps1 <путь>`.
