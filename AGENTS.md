## Уроки с кодом на Python — обязательный минимум

Этот раздел написан прямо здесь, потому что Codex загружает только этот файл. Если просят урок, лекцию или параграф с кодом на Python, **перед началом прочитайте** четыре файла:

1. [`docs/prompts/Code_Lesson_Generator.md`](docs/prompts/Code_Lesson_Generator.md) — структура урока и критерии приёмки.
2. [`docs/13_Code_Module_Python.md`](docs/13_Code_Module_Python.md) — модуль «Код», вместе с приложением А (эталоном).
3. [`docs/03_Math_Notation.md`](docs/03_Math_Notation.md), раздел 2 — правила раскраски, включая `ENF-MATH-025`.
4. [`materials/RL/Q_Learning_Frozen_Lake.learning.md`](materials/RL/Q_Learning_Frozen_Lake.learning.md) — полный урок, принятый автором как эталон.

Требования, которые проверяет автор:

- **Сквозная раскраска (`ENF-MATH-025`).** Символ с ролью окрашивается макросом (`\enfVar`, `\enfFun`, `\enfPar`, `\enfOp`, `\enfTgt`) при **каждом** появлении: в выключных и строчных формулах, таблицах, выносках, разборах, упражнениях и итогах. Недокраска — такая же ошибка, как перекраска.
- **Лимит — до 4 тонов в формуле, и он используется полностью.** Нейтральны только индексы, связанные переменные под $\max$ и $\sum$ (как $a'$), носители, скобки и знаки. В ручном расчёте подставленное число наследует тон символа: $\enfPar{0{,}9}$. Блок `aligned` — одна формула: при пяти ролях разбейте его на несколько `$$`.
- **Таблица «формула → код» для каждой ключевой формулы.** Ровно две колонки: слева окрашенная часть формулы, справа `код` — одно предложение о смысле. Не меньше 4 строк; граничные условия и сдвиги индексов идут отдельными строками; последняя строка — «вся формула» и полная строка кода.
- **Схема шага:** текст с формулой → `python` с маркерами `# (1)` → `output` → таблица «формула → код» → `**Разбор.**` по маркерам → сравнение с ручным расчётом. Для циклов нужна трассировка.
- **Итоговая таблица** «Математика | Python»: 4–8 строк с полными окрашенными формулами, не с их названиями.
- **Вывод только настоящий.** Блоки `output`, трассировки и числа в тексте берутся из фактического запуска. После любой правки кода запустите урок заново и обновите все числа.

Проверки для урока (PowerShell, из корня репозитория):

```powershell
$env:PYTHONIOENCODING = "utf-8"
uv run --no-project --with "numpy>=2.0" python Build/check_lesson.py <файл>   # или python, если он установлен
node Scripts/check-colors.mjs <файл>   # ни одного предупреждения ENF-MATH-025
pwsh Scripts/check.ps1 <файл>
```

Если песочница не даёт `uv` скачать пакеты, не пишите вывод по памяти. Попросите автора выполнить команду и дождитесь результата.
