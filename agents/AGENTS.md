# agents/AGENTS.md — точка входа для ИИ-агентов

Файл лежит в корне по общепринятому соглашению: агент, открывший репозиторий, читает его первым. Здесь только самое необходимое. Полная конституция — [`CODEX.md`](CODEX.md), и без неё материал проверки не пройдёт.

## Что это за репозиторий

Ermakov Notes Framework — фреймворк для научных и образовательных материалов по математике, Data Science и Reinforcement Learning. Содержание материалов на русском; имена файлов, код и команды — на английском.

## Пять правил, нарушение которых обесценивает работу

1. **Не выдумывать источники.** Нет уверенности в ссылке — пишите `TODO(источник)`. Правдоподобная несуществующая ссылка проходит беглую проверку и обнаруживается позже всего (`ENF-AI-001`).
2. **Не выдумывать возможности инструментов.** Несуществующий флаг Pandoc или плагин Obsidian стоит автору часа отладки (`ENF-AI-002`).
3. **Не пропускать шаги вывода.** «Очевидно» без названного основания запрещено (`ENF-AI-003`).
4. **Назначить роли до написания формул.** Роли, выбираемые по ходу письма, расползаются (`ENF-AI-010`).
5. **Прогнать проверки до слов «готово».** `pwsh Scripts/check.ps1 <путь>`.

## Цвет: пять ролей, макросы вместо HEX

Цвет закреплён за **ролью сущности в конкретной формуле**, а не за буквой. HEX-код в тексте материала запрещён: значения живут в единственном месте — `css/enf-tokens.css` (`ENF-COLOR-001`).

| Макрос | Роль | Что окрашивает |
|--------|------|----------------|
| `\enfVar{}` | объект, над которым действуем | $x$, $x_0$, $s$, входные данные |
| `\enfFun{}` | действие, преобразование | $f$, $a$, слой сети |
| `\enfPar{}` | то, что настраивается | $\theta$, $\alpha$, $\varepsilon$, $\delta$ |
| `\enfOp{}` | агрегат, свёртка | $\sum$, $\int$, $\mathbb{E}$, $\nabla$, $V$, $Q$ |
| `\enfTgt{}` | цель | $L$, $r$, $\mathcal{L}$, $y$ |

```latex
% плохо: HEX по месту, не переносится в DOCX, ломает единый источник истины
\lim_{\textcolor{#2563EB}{x}\to\textcolor{#8E44AD}{a}} \textcolor{#E67E22}{f}(\textcolor{#2563EB}{x}) = \textcolor{#16A34A}{L}

% хорошо: роли, три тона, собирается во все пять форматов
\lim_{\enfVar{x} \to \enfVar{a}} \enfFun{f}(\enfVar{x}) = \enfTgt{L}
```

Ролей ровно пять, и это измеренная граница, а не вкус: дихроматия сводит цветовое пространство к светлоте и оси «синее — жёлтое», и уже на шести тонах пары становятся неразличимы (ΔE₀₀ ≈ 2–5 при пороге заметности 2,3). Обоснование и числа — [`../docs/02_Color_System.md`](../docs/02_Color_System.md), проверка воспроизводится командой `node Scripts/check-contrast.mjs`.

## Лимиты раскраски

| Режим | Тонов в формуле | Разрешённые тона | Доля окрашенного |
|-------|-----------------|------------------|------------------|
| `learning` | до 4 | все пять | ≈ 40 % |
| `publication` | до 3 | `\enfVar`, `\enfFun`, `\enfPar` | ≈ 15 % |

Скобки, знаки операций, индексы и запятые не окрашиваются никогда (`ENF-MATH-020`).

В `learning` символ с ролью окрашивается при **каждом** появлении, а лимит тонов используется полностью (`ENF-MATH-025`). Для уроков с кодом на Python обязательны таблицы «формула → код» — см. корневой [`../AGENTS.md`](../AGENTS.md), раздел «Уроки с кодом на Python», и промт [`../docs/prompts/Code_Lesson_Generator.md`](../docs/prompts/Code_Lesson_Generator.md).

## Структура материала

Фронтматтер с `title`, `enf_mode`, `discipline` → раздел «Обозначения» таблицей «символ, значение, роль» → интуиция до формализма → определения и утверждения коллаутами → разобранные примеры → упражнения → итоги.

Таблица обозначений и есть легенда цветов: она сообщает роль каждого символа словами, поэтому смысл не теряется в чёрно-белой печати и в DOCX, где цвет формул снимается (`ENF-COLOR-003`).
