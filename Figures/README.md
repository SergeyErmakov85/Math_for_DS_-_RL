# Figures — растровые иллюстрации и готовые изображения

Каталог для изображений, которые не являются редактируемыми SVG: фотографии, скриншоты интерфейсов, растровые результаты расчётов, экспортированные графики.

## Правила

- Формат — PNG для схем и скриншотов, JPEG только для фотографий. Векторное содержимое в растр не переводится: ему место в [`../SVG/`](../SVG/).
- Имя файла отражает содержимое и материал: `bellman-backup-diagram.png`, а не `image1.png`.
- Каждое изображение вставляется с осмысленным alt-текстом; отсутствие alt-текста ломает проверку `ENF-DIAG-030` 🤖.
- Разрешение — не менее 2× от предполагаемого размера на странице, чтобы изображение не размывалось в PDF.
- Если изображение получено расчётом, рядом кладётся скрипт или ссылка на него в подписи: рисунок должен быть воспроизводим.

Каталог пуст в версии 1.0.0 — все иллюстрации фреймворка векторные. Он существует, чтобы растровым файлам было куда попадать, не смешиваясь с библиотекой SVG.
