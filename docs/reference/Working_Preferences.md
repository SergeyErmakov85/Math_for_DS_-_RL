# Рабочие предпочтения: учебные материалы по PDF

Эта памятка фиксирует согласованный формат дальнейшей работы с учебными PDF в данном репозитории.

## Назначение

По умолчанию готовить русскоязычную учебную мини-статью по содержимому PDF для уровня, который следует из сложности источника. Для школьных вводных тем ориентир — 10–11 класс.

## Репозиторий и место результатов

- Рабочий репозиторий — `Math_for_DS_&_RL`. Его `AGENTS.md`, документы в `agents/` и нормы в `docs/` являются источником обязательных инструкций для каждой задачи.
- Все итоговые пользовательские файлы форматов `.md` и `.docx` сохраняются в `N:\OBSIDIAN\Проекты\Math_for_DS_&_RL\Vault`.
- Папка репозитория используется для исходных материалов, инструкций, проверок и служебных сценариев. Не сохранять в ней итоговый учебный файл, если пользователь явно не попросил иначе.

## Педагогическая структура

Материал содержит:

1. Заголовок и короткий блок о теме.
2. Интуитивное объяснение до формализма.
3. Определения, обозначения и формулы.
4. Один подробный пример с нумерованными шагами и основаниями каждого перехода.
5. Одну типовую задачу с условием, стратегией, вычислениями, проверкой и ответом.
6. Краткий итоговый конспект.

Не добавлять отвлечённую теорию. Если условие или фрагмент источника не читается, не восстанавливать его по догадке: ставить `TODO(проверить источник)` или запрашивать уточнение.

## Цвет формул

Материалы создаются в режиме `learning`. Каждая выключная формула и каждое содержательное встроенное математическое выражение должны содержать семантическую раскраску.

| Роль | Макрос | Типичный смысл |
|---|---|---|
| variable | `\enfVar{}` | аргумент, объект рассмотрения |
| function | `\enfFun{}` | функция или преобразование |
| parameter | `\enfPar{}` | заданная точность, коэффициент, условие |
| operator | `\enfOp{}` | агрегирующий оператор |
| target | `\enfTgt{}` | искомый результат, предел, ответ |

Раскрашиваются все значимые роли, присутствующие в формуле. Скобки, знаки операций, запятые и индексы без отдельной семантической роли остаются нейтральными: это сохраняет читабельность и не нарушает `ENF-MATH-020`.

## Иллюстрации и проверка

- Добавлять блок `[ILLUSTRATION: ...]`, когда график или схема помогают понять идею.
- Для функций и пределов описывать оси, область построения, ключевые точки, линии и семантические цвета.
- При создании DOCX использовать Documents-процесс: собрать файл, отрендерить страницы в PNG, визуально проверить их и исправить дефекты. Если в среде нет LibreOffice, выполнить структурную проверку и явно сообщить, что визуальный рендеринг недоступен.

## Формат результата

По запросу создавать отдельные `.md` и `.docx` в `N:\OBSIDIAN\Проекты\Math_for_DS_&_RL\Vault`, без служебных токенов цитирования внутри документа. Источник указывать обычным читаемым текстом.
