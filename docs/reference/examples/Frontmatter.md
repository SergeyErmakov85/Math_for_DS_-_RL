# Фронтматтер: минимальный и полный

Мини-пример к правилам `ENF-PUB-001`–`ENF-PUB-005`.

## Минимальный

Три поля, без которых материал не проходит проверку:

```yaml
---
title: "Уравнение Беллмана"
enf_mode: learning
discipline: rl
---
```

## Полный: лекция

```yaml
---
title: "Уравнение Беллмана для функции ценности состояния"
enf_mode: learning
discipline: rl
tags: [rl, беллман, динамическое программирование]
duration: 90
date: 2026-07-31
---
```

## Полный: глава книги

```yaml
---
title: "Динамическое программирование в конечных МППР"
enf_mode: publication
discipline: rl
chapter: 4
tags: [rl, динамическое программирование]
date: 2026-07-31
---
```

## Полный: статья

```yaml
---
title: "Влияние коэффициента дисконтирования на скорость сходимости"
enf_mode: publication
discipline: rl
authors: ["Ермаков С. В."]
tags: [rl, сходимость]
date: 2026-07-31
status: draft
---
```

## Материал, перенесённый из источника

Поле `source` фиксирует, откуда взято содержимое, — без него через год будет неясно, что в материале авторское, а что переложение:

```yaml
---
title: "Фундаментальные последовательности и критерий Коши"
enf_mode: learning
discipline: calculus
source: "с. 47, определение 3.2 — теорема 3.3"
date: 2026-07-31
---
```

## Частые ошибки

| Ошибка | Почему это ошибка |
|--------|-------------------|
| `date: 31.07.2026` | не ISO-формат: не сортируется и читается по-разному в разных локалях (`ENF-PUB-004`) |
| `enf_mode: Learning` | значение регистрозависимо; допустимы только `learning` и `publication` |
| `discipline: математика` | значение выбирается из закрытого списка: `calculus`, `linalg`, `probability`, `statistics`, `ml`, `rl`, `optimization`, `meta` |
| `title` не совпадает с `#` | заголовок документа и метаданные расходятся; в оглавлении и в тексте окажутся разные названия |
| незакрытый блок `---` | Pandoc не получит метаданных, а фронтматтер попадёт в текст (`ENF-PUB-001`) |

Проверяется командой `node Scripts/check-frontmatter.mjs`.
