# Codex — конституция ИИ-агентов и контроль качества

Документы этого каталога рассчитаны на то, что агент получает **только их** — без истории диалога — и после этого выдаёт материал, проходящий чек-лист.

| Файл | Назначение |
|------|------------|
| [`AGENTS.md`](AGENTS.md) | Конституция: правила генерации, правила проверки, структура вывода, запреты |
| [`Prompt_Standard.md`](Prompt_Standard.md) | Единый формат промта: роль, вход, выход, ограничения, примеры |
| [`Review_Checklist.md`](Review_Checklist.md) | Чек-лист ревью; каждый пункт ссылается на номер правила `ENF-*` |
| [`Prompts/`](Prompts/) | Библиотека готовых промтов под конкретные задачи |
| [`Review_Report_Example.md`](Review_Report_Example.md) | Образец отчёта ревью — эталон формата вывода |

Инструкции для Claude вынесены в [`../Claude/`](../Claude/), потому что различаются по способу подключения: `AGENTS.md` читается агентом как часть контекста задачи, а `CLAUDE.md` подхватывается Claude Code автоматически из корня рабочего каталога.
