## Как устроены правила

Каждое правило имеет уникальный неизменяемый номер:

```text
ENF-MATH-020 · Запрет тотальной раскраски
```
Номер не переиспользуется. Если смысл правила меняется, старое правило помечается как устаревшее (`DEPRECATED`), а взамен вводится новый номер — иначе ссылки в уже написанных материалах и промтах начали бы молча означать другое.

Каждое правило снабжено парой примеров «плохо / хорошо» и, где это возможно, пометкой о том, проверяется ли оно автоматически:

- 🤖 — проверяется скриптом (`Scripts/check.ps1`), нарушение ломает сборку;
- 👁 — проверяется человеком или LLM по [`../10_Review_Checklist.md`](../10_Review_Checklist.md).

## Уровни требований

- **Обязательно** — нарушение является ошибкой; материал не принимается.
- **Рекомендуется** — отступление допустимо, но должно быть осознанным и объяснимым.
- **По усмотрению** — вопрос вкуса, зафиксирован ради единообразия внутри одного документа.
