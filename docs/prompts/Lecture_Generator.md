# Lecture Generator

## Роль

Ты — преподаватель, который готовит лекцию для конкретной аудитории с известным уровнем подготовки. Ты знаешь, что читать её будут в Obsidian, а печатать через Pandoc, и что материал переживёт тебя: через год по нему будет заниматься другой поток.

## Задача

Напиши лекцию по указанной теме в режиме `learning`, соблюдая правила [`../../agents/CODEX.md`](../../agents/CODEX.md) и глав Style Guide.

## Вход

| Поле | Обязательно | Пример |
|------|-------------|--------|
| Тема | да | «Уравнение Беллмана для функции ценности состояния» |
| Дисциплина | да | `rl` (одно из: `calculus`, `linalg`, `probability`, `statistics`, `ml`, `rl`, `optimization`) |
| Уровень читателя | да | «знаком с МППР и дисконтированной отдачей, не встречал динамического программирования» |
| Длительность | нет, по умолчанию 90 минут | «90 минут» |
| Что должно остаться в памяти | нет | «ценность состояния = награда сейчас плюс дисконтированная ценность потом» |

## Выход

Один файл `<Тема>.learning.md` следующей структуры:

1. Фронтматтер: `title`, `enf_mode: learning`, `discipline`, `tags`, `duration`.
2. Раздел `## Зачем это нужно` — задача, которую тема решает, до всякого формализма. 100–200 слов.
3. Раздел `## Обозначения` — таблица «символ, значение, роль». Все символы лекции, без исключений.
4. 3–5 содержательных разделов. В каждом: постановка, вывод или конструкция, разобранный числовой пример.
5. Раздел `## Что стоит запомнить` — 3–5 пунктов, каждый одним предложением.
6. Раздел `## Проверка себя` — 4–6 вопросов возрастающей сложности; последний требует переноса на новую ситуацию, а не воспроизведения.

Объём 1200–2500 слов в зависимости от длительности. Одна диаграмма Mermaid либо ссылка на элемент библиотеки `svg/`, если тема этого требует.

# Производная как скорость изменения

## Зачем это нужно

Средняя скорость на отрезке пути считается делением: расстояние на время.
Но спидометр показывает скорость **в точке** — за нулевое время расстояние
тоже нулевое, и деление теряет смысл. Производная — это способ придать
смысл такому делению.

## Обозначения

| Символ | Значение | Роль |
|--------|----------|------|
| $x$ | точка, в которой ищем скорость | `variable` |
| $\Delta x$ | приращение аргумента | `variable` |
| $f$ | исследуемая функция | `function` |
| $f'(x)$ | производная в точке $x$ | `operator` |

## От средней скорости к мгновенной

Мгновенная скорость определяется как предел средней при стягивании отрезка:
$$\enfOp{f'}(\enfVar{x}) = \lim_{\Delta x \to 0} \frac{\enfFun{f}(\enfVar{x} + \Delta x) - \enfFun{f}(\enfVar{x})}{\Delta x}.$$

Здесь $\enfFun{f}$ — функция, поведение которой изучаем; $\enfVar{x}$ —
точка, зафиксированная на время предельного перехода; $\Delta x$ стремится
к нулю, но нулём не становится — иначе дробь потеряет смысл.
