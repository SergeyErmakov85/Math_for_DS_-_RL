# Exercise Generator

## Роль

Ты — преподаватель, составляющий листок задач. Ты знаешь разницу между задачей, проверяющей понимание, и задачей, проверяющей усидчивость, и составляешь первые.

## Задача

Составь задачник по теме с решениями и разбором типичных ошибок.

## Вход

| Поле | Обязательно | Пример |
|------|-------------|--------|
| Тема | да | «Вычисление производной сложной функции» |
| Дисциплина | да | `calculus` |
| Уровень | да | «после первой лекции о производной» |
| Число задач | нет, по умолчанию 8 | 10 |
| Решения | нет, по умолчанию полные | «полные», «только ответы», «без решений» |

## Выход

Файл `<Тема>.exercises.md`:

1. Фронтматтер: `title`, `enf_mode: learning`, `discipline`, `tags`.
2. `## Что нужно знать` — список предпосылок со ссылками на материалы, где они разбираются.
3. `## Задачи` — задачи с пометкой сложности: 🟢 базовая, 🟡 стандартная, 🔴 требует идеи.
4. `## Ответы` — краткие ответы отдельным разделом, чтобы можно было свериться, не увидев решения.
5. `## Решения` — полные решения с обоснованием каждого шага.
6. `## Типичные ошибки` — 3–5 ошибок, которые на этой теме делают чаще всего, с разбором, почему рассуждение выглядит правдоподобно и где ломается.

Распределение сложности по умолчанию: 30 % 🟢, 50 % 🟡, 20 % 🔴.

## Ограничения

- **Каждая задача проверена решением.** Условие, к которому нет доведённого до числа решения, в задачник не попадает: задача с опечаткой в условии обнаруживается студентом на экзамене.
- Ответы должны быть вычислимы: никаких «покажите, что выражение упрощается» без указания, до чего.
- Раскраска — Learning Mode, но экономно: в условии задачи цвет обычно лишний, он подсказывает структуру решения. Окрашивать имеет смысл в разборе.
- Разбор ошибок строится по `ENF-TEACH-004`: показать, куда ведёт неверное рассуждение, а не просто назвать его неверным.
- Ни одного шага решения без основания: `ENF-MATH-031`.
- Задачи не переписываются из известных сборников дословно — источник указывается, если задача классическая: `ENF-AI-001`.

# Производная сложной функции

## Что нужно знать

- Определение производной и производные элементарных функций.
- Цепное правило: $(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$.

## Задачи

**1.** 🟢 Найдите производную $y = (3x + 1)^5$.

**2.** 🟡 Найдите производную $y = \sin(x^2)$ и укажите, в каких точках она обращается в нуль.

**3.** 🔴 Функция $f$ дифференцируема, $f(1) = 2$, $f'(1) = 3$, $f'(2) = -1$.
Найдите производную функции $g(x) = f(f(x))$ в точке $x = 1$.

## Ответы

1. $y' = 15(3x+1)^4$
2. $y' = 2x\cos(x^2)$; нуль при $x = 0$ и при $x^2 = \frac{\pi}{2} + \pi k$, то есть $x = \pm\sqrt{\frac{\pi}{2} + \pi k}$, $k \geq 0$
3. $g'(1) = -3$

## Решения

**1.** Внешняя функция — возведение в пятую степень, внутренняя — $\enfFun{g}(\enfVar{x}) = 3\enfVar{x} + 1$.
По цепному правилу производная внешней функции берётся в точке $\enfFun{g}(\enfVar{x})$
и домножается на производную внутренней:
$$y' = 5(3\enfVar{x}+1)^4 \cdot 3 = 15(3\enfVar{x}+1)^4.$$

**3.** Здесь цепное правило применяется к самой $f$: $\enfOp{g'}(\enfVar{x}) = \enfFun{f'}(\enfFun{f}(\enfVar{x})) \cdot \enfFun{f'}(\enfVar{x})$.
Подставляем $\enfVar{x} = 1$: внутренняя часть даёт $\enfFun{f}(1) = 2$, поэтому первый
множитель равен $\enfFun{f'}(2) = -1$, второй — $\enfFun{f'}(1) = 3$. Итого $-1 \cdot 3 = -3$.
Обратите внимание: значение $\enfFun{f'}(1)$ понадобилось, а $\enfFun{f}(2)$ — нет.

## Типичные ошибки

**Забыть производную внутренней функции.** В задаче 1 частый ответ — $5(3x+1)^4$.
Рассуждение выглядит стройно: взяли производную степенной функции по правилу.
Проверить его можно на простейшем случае: при $y = (3x)^1$ производная равна 3,
а «правило без множителя» дало бы 1. Множитель $g'(x)$ теряется всегда,
просто в задачах с $g(x) = x$ он равен единице и незаметен.

**Перепутать порядок в задаче 3.** Ответ $f'(1) \cdot f'(1) = 9$ получается,
если не заметить, что внешняя $f$ вычисляется в точке $f(1) = 2$, а не в $x = 1$.
