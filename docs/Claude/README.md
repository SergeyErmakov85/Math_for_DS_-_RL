| Файл | Назначение |

## Важно: два разных `CLAUDE.md`

В репозитории два файла с этим именем, и путать их не следует.

| Путь | Что это |
|------|---------|
| `/CLAUDE.md` (корень) | Мастер-промт проекта: постановка задачи на построение самого фреймворка |
| `docs/Claude/CLAUDE.md` | Инструкция по **использованию** фреймворка при написании материалов |

Первый отвечает на вопрос «как построить ENF», второй — «как писать лекцию по правилам ENF». При работе над материалами подключайте второй.
