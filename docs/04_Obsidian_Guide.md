# Obsidian — репозиторий и есть хранилище

Корень репозитория — папка `Math_for_DS_&_RL` — открывается в Obsidian как самостоятельное хранилище. Настройки, тема, CSS-сниппеты и плагин формул лежат в корневом `.obsidian/` и версионируются вместе с материалами, поэтому клон репозитория на другой машине выглядит так же, как у автора. Второго, вложенного хранилища нет: одна папка — один источник истины.

## Установка

1. Obsidian → **Open folder as vault** → выбрать корень репозитория `Math_for_DS_&_RL`.
2. Разрешить плагины сообщества (**Turn on community plugins**, при запросе — **Trust author**). В поставке идёт Extended MathJax; он загружает [`preamble.sty`](../preamble.sty) при старте, и макросы раскраски формул определены сразу.
3. Проверить включённые сниппеты в **Settings → Appearance → CSS snippets**: `enf-tokens`, `enf-math`, `enf-callouts`, `enf-code`. В поставке они уже включены через `.obsidian/appearance.json`.
4. Установить в систему шрифт JetBrains Mono — его использует подсветка кода; без него подставится следующий моноширинный шрифт.
5. По желанию — плагины Templater, Dataview и Tasks из официального каталога сообщества.

Хранилище открывается и работает **без плагинов**. Без них недоступны автозаполнение шаблонов и динамические списки материалов, а преамбулу MathJax приходится подключать вручную — открытием [`Obsidian/mathjax-preamble.md`](../Obsidian/mathjax-preamble.md) один раз за сессию. Структура, темы и оформление коллаутов не страдают.

> [!warning] Не открывайте материалы через внешнее хранилище
> Если папка репозитория лежит внутри другого хранилища Obsidian, правьте материалы только из хранилища `Math_for_DS_&_RL`. Внешнее хранилище при переименовании и переносе файлов переписывает ссылки в своих путях — вида `Education/Math/Math_for_DS_&_RL/…` — и они ломаются и на GitHub, и в сборке Pandoc. Проверка `node Scripts/check-links.mjs .` такие ссылки находит.

## Что где лежит

| Путь | Содержимое |
|------|------------|
| `.obsidian/` | настройки хранилища: тема, сниппеты, плагин, формат ссылок |
| `.obsidian/snippets/` | `enf-tokens.css`, `enf-math.css`, `enf-callouts.css`, `enf-code.css` — все порождаются скриптом |
| `.obsidian/plugins/obsidian-latex/` | Extended MathJax — единственный плагин в поставке |
| `.obsidian/themes/` | Obsidianite (включена), Flexoki, Kakano |
| `.obsidian/templates.json` | папка шаблонов для штатного плагина Templates — `templates/` |
| `preamble.sty` | преамбула MathJax, которую плагин читает из корня хранилища |
| `math-textbook/` | учебник: 7 частей, 51 раздел |
| `materials/` | отдельные лекции по дисциплинам; сюда же Obsidian кладёт новые заметки |
| `Obsidian/` | служебные заметки: запасная преамбула, справка по палитре, запросы Dataview, карта курса |
| `templates/` | шаблоны документов; `templates/templater/` — версии для плагина Templater |
| `Figures/` | растровые вложения; сюда Obsidian сохраняет вставленные изображения |
| `svg/`, `mermaid/` | библиотеки иллюстраций и диаграмм |

Служебные каталоги сборки (`Build/`, `Scripts/`, `css/`, `snippets/`) видны в хранилище, но в заметках не участвуют. Результаты сборки в `out/` исключены из поиска и графа настройкой **Excluded files**.

## Настройки ссылок

В `.obsidian/app.json` заданы Markdown-ссылки (`useMarkdownLinks`) в формате относительного пути (`newLinkFormat: relative`) с автоматическим обновлением при переносе файлов. Так ссылка, вставленная в Obsidian, одинаково работает на GitHub, в проверке `check-links.mjs` и в сборке Pandoc (`ENF-TYPO-051`). Wiki-ссылки `[[…]]` допустимы только в служебных заметках `Obsidian/` и в Templater-шаблонах.

## Сниппеты не редактируются вручную

Все файлы в `.obsidian/snippets/` — **порождённые**. Они создаются из источников `css/enf-tokens.css`, `snippets/enf-math.css`, `snippets/enf-callouts.css` и `snippets/enf-code.css` командой:

```powershell
node Scripts/gen-obsidian-css.mjs
```

Правки, внесённые прямо в сниппет, теряются при следующей генерации. Менять нужно источник — там же лежит и обоснование выбора цветов. Подробнее — [`05_CSS_Guide.md`](05_CSS_Guide.md); палитра подсветки кода — [`13_Code_Module_Python.md`](13_Code_Module_Python.md), п. 10.

## Рендер формул

Obsidian использует MathJax. Раскраска строится на макросах `\enfVar`, `\enfFun`, `\enfPar`, `\enfOp`, `\enfTgt`, которые вешают CSS-класс, а не фиксируют цвет: формула перекрашивается при смене темы сама, а единый источник истины сохраняется.

У самого Obsidian настройки постоянной преамбулы MathJax нет. Её даёт плагин Extended MathJax: он читает `preamble.sty` из корня хранилища при старте приложения. Плагин и преамбула лежат внутри репозитория, поэтому клон на другой машине раскрашивает формулы сразу. Запасной путь на случай выключенных плагинов — заметка `Obsidian/mathjax-preamble.md`, открытая один раз за сессию; там же описана диагностика. При правке макросов правятся оба файла. При сборке через Pandoc проблемы нет: там макросы объявлены в LaTeX-преамбуле и доступны всегда.
