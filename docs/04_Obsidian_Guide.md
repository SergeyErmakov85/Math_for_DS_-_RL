# Obsidian — готовое хранилище «скопировал и работай»

Рабочие файлы лежат внутри [`Obsidian/Vault/`](../Obsidian/Vault/): Obsidian видит только содержимое своей папки, поэтому держать вторую копию снаружи означало бы два источника истины и расхождение между ними. Каталоги `CSS/`, `Templates/`, `Canvas/`, `Dataview/`, `Snippets/`, `Icons/` содержат README с указанием, где именно лежит соответствующая часть.

## Установка

1. Obsidian → **Open folder as vault** → выбрать `Vault/` (или её копию в удобном месте).
2. Открыть [`Obsidian/Vault/_meta/mathjax-preamble.md`](../Obsidian/Vault/_meta/mathjax-preamble.md) — без этого макросы раскраски формул не определены.
3. Проверить включённые сниппеты в **Settings → Appearance → CSS snippets**: `enf-tokens`, `enf-math`, `enf-callouts`. В поставке они уже включены через `.obsidian/appearance.json`.
4. По желанию — плагины Templater, Dataview, Tasks из официального каталога сообщества.

Хранилище открывается и работает **без плагинов**. Без них недоступны автозаполнение шаблонов и динамические списки материалов; структура, темы и оформление формул не страдают.

## Что внутри хранилища

| Путь | Содержимое |
|------|------------|
| `Vault/.obsidian/snippets/` | `enf-tokens.css`, `enf-math.css`, `enf-callouts.css` — все три порождаются скриптом |
| `Vault/_meta/` | преамбула MathJax, справка по палитре, библиотека запросов Dataview |
| `Vault/_templates/` | Templater-версии шаблонов |
| `Vault/_canvas/` | `course-map.canvas` — карта зависимостей тем |
| `Vault/00…90` | рабочие папки материалов по типам |

## Сниппеты не редактируются вручную

Все три файла в `Vault/.obsidian/snippets/` — **порождённые**. Они создаются из источников `css/enf-tokens.css`, `snippets/enf-math.css` и `snippets/enf-callouts.css` командой:

```powershell
node Scripts/gen-obsidian-css.mjs
```

Правки, внесённые прямо в сниппет, теряются при следующей генерации. Менять нужно источник — там же лежит и обоснование выбора цветов. Подробнее — [`05_CSS_Guide.md`](05_CSS_Guide.md).

## Рендер формул

Obsidian использует MathJax. Раскраска строится на макросах `\enfVar`, `\enfFun`, `\enfPar`, `\enfOp`, `\enfTgt`, которые вешают CSS-класс, а не фиксируют цвет: формула перекрашивается при смене темы сама, а единый источник истины сохраняется.

У Obsidian нет настройки постоянной преамбулы MathJax. Макросы объявляются в заметке `_meta/mathjax-preamble.md`, и она должна быть открыта один раз за сессию — ограничение описано в самой заметке вместе со способом его обойти. При сборке через Pandoc этой проблемы нет: там макросы объявлены в LaTeX-преамбуле и доступны всегда.
