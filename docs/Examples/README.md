# docs/Examples — мини-примеры к правилам

Короткие фрагменты (5–20 строк), иллюстрирующие отдельные правила Style Guide. Используются как справочный материал и как эталонный вход для промтов.

| Файл | Иллюстрирует |
|------|--------------|
| [`Coloring_Modes.md`](Coloring_Modes.md) | Разницу между Learning Mode и Publication Mode на одной и той же формуле (`ENF-MATH-020`, `ENF-MATH-021`) |
| [`Frontmatter.md`](Frontmatter.md) | Минимальный и полный фронтматтер (`ENF-PUB-001`–`ENF-PUB-004`) |
| [`Callouts.md`](Callouts.md) | Оформление определений, теорем, замечаний (`ENF-TYPO-030`, `ENF-MATH-040`) |

Полностью оформленные документы, проходящие сборку во все пять форматов, лежат в корневом каталоге [`../../Examples/`](../../Examples/).
